# Forma

App personale (PWA) per allenamenti, dieta e acqua. Si installa sull'iPhone dalla schermata Home.

## Pubblicazione su GitHub Pages
1. Crea un repository pubblico `forma` su github.com/riccardocaccia
2. Carica tutti i file di questa cartella (index.html deve stare nella radice)
3. Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)` → Save
4. Dopo 1-2 minuti l'app è su `https://riccardocaccia.github.io/forma/`

## Installazione su iPhone
Apri il link in **Safari** → Condividi → **Aggiungi alla schermata Home**.

## Aggiornamenti
Modifica i file e fai `git push`: all'apertura successiva (con internet) l'app si aggiorna da sola.
I tuoi dati restano sul telefono e non vengono toccati dagli aggiornamenti.

## Backup
Impostazioni → Esporta backup. Ogni tanto salvalo su iCloud Drive.
